IdeaNote

AI 智能写作

一款基于 Electron 的跨平台桌面应用，专为创意写作者打造。集成了先进的 AI 技术，提供智能写作辅助、富文本编辑等功能。

📝 智能编辑器

  • 基于 Tiptap 的 Notion 风格 WYSIWYG 编辑器
  • 集成 DeepSeek AI，支持文稿润色与语法检查
  • 支持数学公式、代码块、实时 Markdown 预览

🤖 AI 写作助手

  • 内容扩写/缩写：智能扩展或提炼文本
  • 创意生成：营销文案、教程、课程大纲模板
  • 流式响应：实时 AI 内容生成体验

🛠️ 技术架构

Electron + React 18 + TypeScript | Vite 构建

Tailwind CSS 美学 | Radix UI 组件库

VideoFlow

视频全流程管理
VideoFlow 界面预览区

一款专注于提升企业视频制作效率的全流程管理平台，适用于企业培训、短视频营销及在线课程制作。

🎥 核心功能

  • 项目管理：文案管理与制作进度跟踪
  • 脚本工具：PPT 自动生成、智能提词器
  • 素材库：音乐库与封面制作工具

🚀 产品优势

  • 全流程闭环：从文案构思到成片发布
  • AI 赋能：智能语音生成与字幕制作
  • 协作高效：团队成员实时同步状态

🌐 项目测试地址： scrum.ideaswork.cn:3000

💡 提示：可注册账户使用，线上环境仅作测试，每次更新会覆盖数据。

AgileDao

敏捷开发 Scrum

复刻 PingCode 和 禅道 的极简开源 Scrum 管理软件。适合小型团队和独立开发者，旨在实践“敏捷之道”。

📊 管理功能

  • 可视化：用户故事地图与产品待办事项
  • 迭代管理：Sprint 规划与任务分配
  • 工时分析：记录工作时间与燃尽图

🧭 软件含义

敏捷：快速响应需求变化，拥抱 Scrum 框架。

道：不仅是工具，更是实践敏捷开发的路径。
